# 东八外观

菜单栏工具。Mac 的系统时区可以伪装成别的城市，菜单栏上的日期、星期、时间和深浅色则按你实际所在的时区计算。

默认实际时区是台北。两个时区都可以在菜单里改，不写死东八区或纽约。

## 两个时区

**伪装时区**会改 Mac 的系统时区。系统时钟、菜单栏右上角的时间都会变成那个城市的当地时间。点选后要先确认，再输入管理员密码。

**实际时区**不改系统时区。菜单栏里这个程序显示的时间，以及浅色、深色切换，都按它计算。点选后只需确认，不用管理员密码。

时区按洲展开，不把全部城市铺在第一层。偏移来自系统时区数据库，所以纽约在夏令时是 UTC-4，冬令时会变成 UTC-5。

深浅色按实际时区的日出和日落切换。城市坐标来自系统的 `zone.tab`，不是固定的 7:00 和 19:00。例如系统时区停在纽约的中午，而实际时区是台北的半夜，菜单栏显示台北时间，外观是深色。

时钟每到实际时区的下一分钟更新一次，其余时间不轮询。

## 安装

需要 macOS 13 或更新版本。

1. 从 [Releases](https://github.com/a1024053774/DongbaAppearance/releases) 下载 `DongbaAppearance-1.0.zip`，解压后把 `DongbaAppearance.app` 拖进「应用程序」。
2. 第一次打开若被系统拦截，到「系统设置 → 隐私与安全性」里允许，或在 Finder 里按住 Control 点按应用图标后选择「打开」。
3. 深浅色需要允许本程序控制「系统事件」。提示出现时选「允许」。
4. 改伪装时区时，系统会再要一次管理员密码。

也可以把本仓库拉下来自己编译：

```bash
make
open build/DongbaAppearance.app
```

`make run` 会编译并打开。`make test` 跑时区、夏令时和日出日落的检查。`make clean` 删掉 `build/`。
